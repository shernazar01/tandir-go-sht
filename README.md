# Jarqo‘rg‘on Tandir Go‘shti

React + Vite sayti. Qora-oltin dizayn, mobil moslashuv, UZ/RU/EN interfeys, menyu, savat va buyurtma formasi mavjud.

## Ishga tushirish
```bash
npm install
npm run dev
npm run build
```
